# まなびツールBOX 第3版 — アプリ追加しやすい構成

第2版の見た目、授業タイマー、ランダム指名ツール、かけ算チャレンジ、お気に入り、検索を引き継ぎました。新たに「学習ふりかえりカード」を追加しています。

## フォルダー構成
```
index.html                   トップページ（基本的に編集不要）
assets/tools.js              ツール登録一覧（新しく登録するときに編集）
apps/kanji/README.md         国語アプリ用の場所
apps/math/README.md          算数アプリ用の場所
apps/social/README.md        社会科アプリ用の場所
apps/teacher/README.md       授業支援アプリ用の場所
apps/teacher/reflection/index.html  学習ふりかえりカード
README.md                    この説明書
```

## 既存の公開サイトを第3版に更新する【重要】
GitHubにログインし `manabi-toolbox` を開きます。ブラウザの `Add file → Upload files` で、ZIPを解凍したフォルダーの中の **ファイルとフォルダーを全部選択してアップロード** します。ブラウザやOSによってはフォルダーを正しく取り込めない場合があります。必ずアップロード前の変更一覧で **assets/tools.js** と **apps/teacher/reflection/index.html** がリポジトリ内の正しい階層になることを確認してください。`index.html` が最上位にあることも確認してください。`Commit changes` で保存します。元の `index.html` は上書きして構いません。

**より確実な方法**：アップロード画面へ解凍した `index.html` と `README.md`、さらに `assets` フォルダーと `apps` フォルダーをドラッグ＆ドロップしてください。GitHubでフォルダー構成が維持できない場合は、GitHub上で `Add file → Create new file` に進み、ファイル名に `assets/tools.js` のようにスラッシュを含むパスを入力して、新規ファイルを作る方法もあります。

## 追加の確認
- 公開ページに4件のツールが表示される
- 「学習ふりかえりカード」から別ページが開く
- 「授業タイマー」「ランダム指名ツール」「かけ算チャレンジ」が動く
- 検索・お気に入りが動く（第2版と同じブラウザならお気に入りは引き継がれます）

## 新しい学習アプリを追加する例
1. `apps/kanji/my-app/index.html` を用意する（ここに作成済みのアプリHTMLを置く）。
2. `assets/tools.js` をGitHubで開き、鉛筆アイコンで編集する。
3. `const TOOLS = [` の中の最後の項目にカンマをつけ、次の内容を追加する。
```javascript
{id:'kanji01',name:'漢字練習',description:'漢字の練習アプリです。',category:'国語',icon:'✏️',external:'./apps/kanji/my-app/',audience:'児童向け',updated:'2026-11-21',featured:false}
```
4. `Commit changes` で保存。公開が反映されたらサイトにツールが増えます。

`id` は重複しない英数字、`external` はアプリの場所（上記の相対URL）にしてください。実際にないアプリのURLを登録するとリンク切れになります。

### GitHubで既存ファイルを差し替えるとき
最上位の `index.html` を上書きするだけでなく、`assets/tools.js` の登録情報も更新してください。ファイルをZIPのままアップロードしてはいけません。新たに追加した `apps/` などのフォルダーを削除しないよう注意してください。

## 安全上の注意
- 公開リポジトリやアプリに児童の名前・成績・写真・連絡先などを記録しないこと。
- 今回のふりかえりカードは入力内容をサーバーへ送らず、ブラウザのリロードで消えます。授業で使う場合、コピー・印刷で必要な情報を手元に残してください。
- お気に入りは利用するブラウザだけに保存され、端末間では同期しません。
- 学校のICT運用規程に従ってください。
